🌸 Setup Otomatis Database

Halaman ini akan otomatis membuat tabel site_stats, policy RLS, dan realtime sync — tanpa perlu buka SQL Editor manual.

📖 Cara Pakai (sekali saja):
  1. Buka supabase.com/dashboard/account/tokens
  2. Klik Generate new token → beri nama ayaka-setup
  3. Copy token (format: sbp_xxxxxxxxxxxx)
  4. Paste di kolom bawah → klik tombol Setup Otomatis
  5. Setelah selesai, hapus token di halaman yang sama (opsional, demi keamanan)
